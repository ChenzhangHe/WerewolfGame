# 原生工具与高思考：修复和验证

## 修复内容

- DeepSeek thinking 的状态只在当前座位、当前决策内存中回传；退出调用即丢弃。
  观众、其他座位、后续决策和导出文件均没有推理原文。长度、摘要与计量用于核对回传链。
- 真实接口探针确认：enabled/high 搭配 `tool_choice: required` 返回 HTTP 400，
  错误为 `Thinking mode does not support this tool_choice`；改用 auto 后成功返回原生工具调用。
  新版 v11 的 off/high 均用 auto，避免对照中混入不同调用方式。
  主持程序仍要求唯一合法原生终结行动，不把普通文字转换成行动，不自动纠错。
- 个人笔记与核心规则直接进入座位简报；笔记明确标作个人信念，不是法官事实。
  不预装整局历史，仍可按需读取完整规则与过滤后的记录。
- 自爆任务以普通白天继续/中断检查呈现，强调维持既有计划、依据新信息评估。
  没有删除合法窗口或动作，没有强制 pass、自爆次数上限或固定战术脚本。
- 增加纯算术工具：公开资格下的假设放逐票型，以及用户明确给出的完整身份假设下的胜负条件。
  后者只校验公开阵容、本人角色、已知狼队名单与公开翻牌，不查询其他隐藏角色；
  未核验角色始终标为假设。它不模拟夜间技能或未来玩家行为。
- 预算为单次 384,000 字符、累计 5,000,000 字符，包含实际思考回传。
  仍限定十二次模型请求、十二次读取；旧协议预算与存档保持原版本。
- 设置界面支持十二席高思考预设：tools、enabled/high、temperature=null、max_tokens=32768。
  高思考 token 和最终输出共用该输出预算；快模式也保留。配置在开局冻结。

## 安全边界与测试

184 项 Python 测试通过，包括跨席并发与后续决策不继承推理、空状态回传、
推理计入预算、导出脱敏、摘要链被篡改时审计失败，以及隐藏身份互换不影响不知情座位。
公开投票资格、白痴存活、Sheriff 1.5 票、弃票、重复/非法票与错误胜负假设也有测试。
JavaScript 语法和 14 项语音界面集成检查通过；分别运行十二席快/高预设，确认未切回 JSON。

思考档案中的 `wire_request` 只移除推理字段，其余完整字段仍可重建检查。
审计器核对同一决策内前后摘要、消息位置和真实长度；因为不保存推理原文，
不能声称逐字复原或语义审查了推理正文。实际回传隔离由调用局部状态与发送载荷测试验证。

## 同协议实测

选用已结束 v9 对局四个座位过滤快照，每种模式各重复两次，共十六次。
只发送该座位当时可访问的资料，不发送整个归档或未来信息，不推进真实对局。
初始消息、工具定义、auto 选择方式、模型、温度省略、32768 输出预算一致，
只改变 thinking 与 effort；后续读取由各模型自己选择。

| 模式 | 决策成功 | 原生模型请求 | 自爆／继续 | 平均耗时 | 思考 token |
| --- | ---: | ---: | --- | ---: | ---: |
| off | 8/8 | 23 | 0／8 | 6.64 秒 | 0 |
| high | 8/8 | 21 | 0／8 | 58.04 秒 | 50,039 |

high 的单次最慢 166.66 秒，确实发生了多轮思考状态回传，并有一次主动使用
`check_win_hypothesis`。所有调用正常结束，未改成 JSON 或自动重试。
数据见 `artifacts/native-strategy-probe-summary.json`；原文过滤请求和脱敏 trace
留在本地 `artifacts/native-strategy-probe-auto.private.json`。
之前 required 配置的失败实验保存在 `artifacts/native-strategy-probe-required.private.json`，未覆盖。

两组行动相同，因此尚未证明 high 比 off 战略更强。新版同时改了信息呈现和问题措辞，
也不能把与旧实战的选择差别全归因于思考强度。此处验证的是新工具协议能真实运行，
没有用强制不爆来制造成功结果。

## 整局验证

完整十二席 high 对局使用相同种子 23223、同样姓名与人格、中文、tools、enabled/high、
temperature=null、max_tokens=32768，关闭纠错重试，从头运行并监督到终局。
该实战的结果、错误与信息边界审计另在结束后追加；不把上述十六次单次决策冒充完整实战。
