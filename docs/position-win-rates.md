# 按座位和角色比较 Sol / Terra 的胜率

这是阵营胜率的描述统计：胜场表示该席位所属阵营最终获胜，不是投票或技能正确率。每格保留胜场／出场数；同一场的席位结果相关，不能把它们当成独立对局。

座位关联固定性格、角色分配与同局队友，因此不能直接把差异解释成“某个座位更强”。历史模型级分组混合了不同思考强度，另列固定 Sol medium／Terra low 的子集供比较。新开对局不读取旧对局记忆。

## 复算与后续更新

```sh
python3 scripts/rate_replays.py --grouping model-family --output artifacts/model-family-ratings.json
```

[JSON 全量统计](../artifacts/model-family-ratings.json)还包含 `win_rates.by_seat_and_role`（座位 × 角色 × 模型）交叉计数。不存在样本的格子是 `null`，不会当成零胜率。新批次每结束一场后，累计 `ratings.json` 都会更新座位和角色统计；本 Markdown 是当前 51 场的快照，后续公布结果时重新生成。

新的十二场预先固定为种子 29000 与 30000 的两组六场，每次最多六场并行。每个模型在新增十二场中占据每个座位六次，获得 24 次狼人、24 次村民、四种神职各 6 次；模型、思考强度、性格、语言和规则不在局内改变。
